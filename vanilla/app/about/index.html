A studio built around a lifecycle

The studio started as a checklist. Set the initial state before the first paint. Play the intro once the targets exist. Settle into plain CSS and clear the temporary styles. Run the outro on the live page before the browser leaves it. Commit only from the completion callback.

That checklist turned out to be the whole job. Most animation bugs are not easing problems, they are ownership problems: two timelines fighting over one element, or a page removed before its exit finished.
